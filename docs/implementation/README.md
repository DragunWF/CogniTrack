## 🎨 Design Philosophy

CogniTrack follows these core principles across all documentation:

### 1. **Dark Theme First**

- Psychology-based color palette
- Reduced eye strain
- Calming, introspective environment

### 2. **Frictionless Interaction**

- One-tap actions where possible
- Minimal cognitive load
- Clear visual hierarchy

### 3. **Awareness Over Perfection**

- Non-judgmental UI/UX
- Focus on patterns, not shame
- Positive reinforcement

### 4. **Privacy-First**

- Local-first data storage
- User owns their data
- No tracking without consent

### 5. **Accessibility**

- WCAG AA compliance
- Screen reader support
- Clear touch targets

## 📝 Contributing to Documentation

When adding or updating documentation:

### Do:

- ✅ Use clear, concise language
- ✅ Include code examples
- ✅ Explain the "why" behind decisions
- ✅ Add visual diagrams where helpful
- ✅ Consider psychology and user experience
- ✅ Keep accessibility in mind
- ✅ Update this index when adding new files

### Don't:

- ❌ Assume prior knowledge
- ❌ Use jargon without explanation
- ❌ Forget to document breaking changes
- ❌ Leave outdated information
- ❌ Skip code comments in favor of separate docs
